# Language-model adaptation: L25–L34

Preserve the full 190-entry objective. These ten entries extend L01–L24; they do not replace the remaining curriculum. Reuse continuous articles, one real player, stable geometry and progress.

| ID | Small mechanism to trace | Changed condition | Boundary |
| --- | --- | --- | --- |
| L25 | Fixed synthetic ND budget; loss = 1 + 4/N + 4/D; lifetime cost adds requests × N | Allocation, data coefficient, inference volume | Illustrative equation, no empirical universal scaling law |
| L26 | Contract validation of supplied extraction fixtures for a two-item receipt | Ambiguity, explicit schema, true/false content, literal instruction-like data | Checks are computed; responses are fixtures, not claimed model observations |
| L27 | Ordered packing of instructions/history/evidence/output into 20 declared units | Summary, missing detail, absent/stale retrieval, output reserve | Units are toy counts; fitting does not prove reliable use |
| L28 | Temperature and candidate filtering on logits [2,1,0]; seeded draws; two-level beam tree | Temperature, top-k, top-p, seed, greedy/beam | Sampling probabilities are not truth; no division by zero |
| L29 | Five arithmetic candidates, majority and exact/weak verifier under a ten-unit budget | Correlated wrong answers, incorrect checker | Supplied candidates; no fabricated model-quality measurement |
| L30 | Binary candidate token probabilities with shared scalar weight, explicit token loss masks and gradient updates | Demonstration style, response-only/all-token loss, prompt-only | Tiny differentiable fixture, not a production LM |
| L31 | Fit pairwise logistic reward on length, then optimize a finite policy with KL reference penalty | Correctness feature, drift coefficient | Reward proxy can favor wrong long answer; finite exact solution is not PPO |
| L32 | DPO on two responses against a reference; feedback sources and tested-case limits | Preference reversal, beta, human/AI/checker disagreement | Checkable case is not universal correctness; no simulated GRPO run |
| L33 | 2×2 frozen base plus actual rank-1 BA; adapter gradients and quantized-base forward pass | Rank, adapter scale, quantization, zero initialization | Quantizer is declared toy rounding, not NF4/full QLoRA |
| L34 | Fit a Bernoulli student to hard/soft teacher targets; shared-parameter two-task retention | Wrong teacher, replay, contradictory later task | Coverage/capacity limits visible; no guarantee of full capability transfer |

Each article must define vocabulary before formulas, trace intermediate states, include a prediction and transfer challenge, and cite checked primary sources. Numerical tests use independent values/finite differences; browser checks include all scenarios at 320px, 200% text, both themes and fixed player geometry. No inert starting-state duplicate above the experiment.
